# 🚀 HHIntegrationTool - интеграция с API HeadHunter

Профессиональное решение для работы с вакансиями с hh.ru через API

## 🔍 Возможности

### 📡 Работа с API HeadHunter
- Поиск вакансий по ключевым словам
- Настройка количества результатов (пагинация)
- Автоматическая проверка подключения к API

### 💼 Управление вакансиями
- Сохранение вакансий в JSON-файл
- Фильтрация по:
  - Ключевым словам в описании/требованиях
  - Диапазону зарплат
- Сортировка по уровню зарплаты
- Удаление вакансий из хранилища

### 📊 Дополнительные функции
- Преобразование данных API в объекты Python
- Валидация данных вакансий
- Защита от дублирования при сохранении

## 📦 Установка и запуск

Создание виртуального окружения и установка зависимостей:

poetry install

## Функциональность
- Получение вакансий с hh.ru по ключевому слову

- Фильтрация вакансий по:
  - Ключевым словам в описании
  - Диапазону зарплат

- Сортировка вакансий по зарплате

- Сохранение вакансий в JSON-файл

- Удаление вакансий из хранилища

## Установка

Клонируйте репозиторий:
git clone https://github.com/EvgeniaBalatskaya/HHIntegrationTool
cd HHIntegrationTool

Создание виртуального окружения и установка зависимостей:
poetry install

## Структура проекта

src/api/ - Модуль для работы с API
src/models/ - Модели данных
src/storage/ - Работа с хранилищем
src/utils/ - Вспомогательные функции
data/ - Хранение данных
tests/ - Тесты

## Тестирование

Проект покрыт тестами на `pytest`.  
Для запуска тестов используйте:

pytest --cov=src tests/

## Разработка

Приложение написано на Python.
Используются стандарты кода PEP 8 и инструменты для статической проверки качества кода (Flake8, mypy).
Для тестирования используется pytest.
Все изменения отслеживаются через Git и GitHub.
